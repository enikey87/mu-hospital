# Портреты авторов отзывов

Решение оператора от 03.11.2026: удалить секции о следующей партии 2374 года и корпоративном управлении; сохранить Московский Институт Обогащения Урины в истории компании; создать портреты по авторам отзывов.

Историческая справка размещена в подвале основного сайта, ссылка «История» ведёт к ней. Будущий выпуск 2374 года исключён также из каталога и FAQ. Коллекционный выпуск 2024 года остаётся архивным и недоступным для заказа.

Изображения созданы встроенным imagegen: отдельный запрос на каждого персонажа. Люди вымышленные, возраст и характер учитывают подписи и тексты обращений. Зинаида изображена орловской рысистой, скальпель — хирургическим инструментом. Организации представлены корреспонденцией; одно изображение Красного Креста используется на обоих сайтах. Тексты отзывов и подписи сохранены.

Файлы: `public/avatars/<slug>-review.webp`, 256×256. Исходники уменьшены и экспортированы в WebP. Изображения загружаются отложенно, при ошибке показываются инициалы. В разделе указано, что изображения созданы нейросетью.

Проверки: `npm test`, `npm run build`. Браузерный прогон: `PLAYWRIGHT_MODULE=/path/to/playwright CHROME_BIN=/path/to/chrome node tools/verify-review-portraits.cjs` при запущенном preview на порту 5188. Инструмент использует отдельно установленный Playwright; новые зависимости в проект не добавлены. `SITE_URL` позволяет проверить опубликованную версию, `REPORT_PATH` задаёт файл результата.
