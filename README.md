# Пансионат «Солнышко» и УринаТех

Основной сайт — пансионат «Солнышко»: направления здравницы, проживание,
питание и справочные бланки путёвок. Из раздела уринотерапии доступен полный сайт производителя
«УринаТех» с каталогом, архивом партий и донорской программой.

Проект — сайт-реставрация легендарного ресурса `urina-ru.narod.ru`
(Московский Институт Обогащения Урины, 2002). Концепция, ассортимент
и правовая позиция оригинала сохранены.

> Имеются противопоказания. Необходима консультация специалиста. 18+

## Навигация

- `/` и `#/` — главная пансионата; `#/solnyshko` сохранён как старый адрес.
- `#/solnyshko/station` — уринотерапия; остальные направления имеют собственные страницы.
- `#/urinatech` — производитель; `#/urinatech?section=products` — его каталог.
- Старые якоря производителя, например `#products` и `#company`, сохраняют назначение.

Решение и таблица маршрутов: [структура сайтов](docs/design/site-hierarchy.md).

У производителя собственный дизайн [«Промышленный монумент»](docs/design/urinatech-monument.md): графит, красный акцент, локальный Oswald и фотографии продукции. Здравница сохраняет бело-синий стиль; темы разделены контейнерами `.ut` и `.sol`.

## Технологический стек

- TypeScript (strict)
- React 18
- MobX 6 (mobx-react-lite)
- Vite 6

## Разработка

```bash
npm install
npm test           # контрактные тесты
npm run dev        # локальный сервер, http://localhost:5173
npm run build      # типы + продакшен-сборка в dist/
npm run preview    # предпросмотр продакшен-сборки
```

## Публикация

Публикация выполняется автоматически через GitHub Actions при пуше в `main`:
тесты, сборка и деплой на GitHub Pages. В pull request выполняются тесты
и сборка без публикации. Настройки Pages: Source → GitHub Actions.

## Структура

```
src/
├── components/   # секции сайта и элементы интерфейса
├── stores/       # MobX-сторы: корзина, верификация, донорская программа, отзывы
├── data/         # каталог продукции, тарифы, правовая позиция, стратегия
└── styles/       # глобальные стили
```
